🆘 TROUBLESHOOTING

Q: "PowerShell won't run the script"
A: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

Q: "Git authentication failed"
A: git config --global user.name "Your Name"
   git config --global user.email "your@email.com"

Q: "Script doesn't find files"
A: Make sure you're in the repo root directory (where .git is)

Q: "Want to undo?"
A: git reset --soft HEAD~1    # Undo commit, keep files
   git reset --hard HEAD~1    # Undo commit, discard files
   git push --force-with-lease # Force push (if already pushed)

See DEPLOYMENT_GUIDE.md for more help
